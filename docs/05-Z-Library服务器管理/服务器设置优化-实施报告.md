## 3. 优化前后布局说明（真机截图已核对）

**Z-Library 设置页**
- 优化前：独立「服务器」卡片含「编辑地址」「连接测试」「配置版本」「服务器配置（候选列表/自动检测）」多个重复入口；多行地址编辑弹窗。
- 优化后：单一「服务器管理」整行入口，显示「自动选择 · 未配置服务器 / 尚未配置服务器地址」（有配置后为「手动选择 · 连接正常 / 地址」），点击进入。搜索偏好「默认语言/分页数量/保存偏好」与修改前完全一致。

**服务器管理页（独立二级页，隐藏外层「设置」标题与底部导航）**
- 顶部：返回 + 「服务器管理」标题 + 右上 ⋮（批量导入/导出/恢复默认）。
- 服务器选择方式：自动选择｜手动选择标签 + 说明文案。
- 当前服务器状态卡：连接状态（尚未连接/已选择·尚未检测/连接正常/连接失败）+ 地址 + 响应耗时/最近检测时间（来自实际探测结果）。
- 服务器列表（N/M 已启用）+ 添加：每行仅序号或单选控件、地址（长地址两行省略）、状态、启用开关、⋮；低频操作收纳菜单；无 ON/OFF 与直接按钮。
- 底部：单一「检测服务器」按钮（检测中显示加载态并防重复）。
- 空列表显示「暂无服务器，请添加服务器地址。」；全禁用显示「没有已启用的服务器。」

真机截图核对：空列表页、三候选（2 启用 1 禁用）、⋮ 菜单五项、手动模式单选、逐层返回均正常。

## 4. 服务器选择与检测逻辑调整结果

- **统一列表**：自动/手动共用 `candidates`，`manualBaseUrl` 仅作旧配置迁移来源，写回为空；切换模式不清空列表。
- **自动选择**：缓存有效期内复用最近成功且仍启用的地址；主动检测按优先级分批并发探测、选优先级最高的可用项（不以耗时为唯一依据）；禁用项不参与；全部失败显示失败态；业务错误（认证/额度/限流）不触发切换；单飞与配置版本防竞态保留。
- **手动选择**：按 `manualSelectedServerId` 从统一列表选择，不主动探测、失败不自动切换；主动检测全部只更新结果不改变选择；切手动优先沿用当前自动选择→历史有效选择→提示用户。
- **删除/禁用当前项**：自动模式清缓存后重新检测选择；手动模式清除选择并提示，不自动切换。
- **优先级排序**：收纳到 ⋮ 的上移/下移，保存后不中断当前连接，下一次自动检测生效。
- **状态真实性**：响应耗时与检测时间来自 `ProbeResult`；占位域名实测显示「连接失败」而非「连接正常」；未检测项不标记正常。

## 5. 旧配置兼容处理结果

- schema v1（字符串 `baseUrls`）→ v2（启用候选）→ v3（统一列表 + 选择关系）连续迁移，读取时自动执行。
- 旧 `manualBaseUrl`：不在候选列表则新建一个启用候选并让手动选择指向它；已在列表则直接指向匹配项（规范化判重，不重复添加）。
- 仅手动模式建立选择关系；自动模式保留地址入列表不丢失。
- 迁移幂等：迁移后再 normalize 结果一致（单测覆盖对象级与完整 JSON 反序列化级）。
- 手动选中项被禁用/删除时自动清除选择关系，`baseUrls` 镜像同步为空。
- 应用升级不覆盖用户已有列表；无经过核实的真实默认地址，默认与「恢复默认」均为空列表（已移除 `https://example.com` 占位）。

## 4. 性能基线

- **进程冷启动**：对测试包执行 5 次 `force-stop` 后 `am start -W`，Android 报告的 `TotalTime` 为 277, 211, 219, 213, 220 ms，中位数 **219 ms**。计时止于 Activity 启动完成，不包含远端加载或完整首屏数据渲染，也不清系统缓存。

| 场景 | 帧数 | Janky frames | P95 帧耗时 | 采样时总 PSS |
| --- | ---: | ---: | ---: | ---: |
| 栏目点击36次 | 1751 | 73 (4.17%) | 12ms | 157.9 MiB |
| 云端二级往返10轮 | 1652 | 100 (6.05%) | 14ms | 184.3 MiB |
| 阅读循环前 | 0 | — | — | 253.0 MiB |
| 阅读面板10轮 | 504 | 23 (4.56%) | 17ms | 275.9 MiB |
| 阅读面板20轮 | 1007 | 46 (4.57%) | 17ms | 271.9 MiB |
| 阅读面板30轮 | 1507 | 68 (4.51%) | 16ms | 272.3 MiB |
| 阅读面板闲置5秒 | 1507 | 68 (4.51%) | 16ms | 261.5 MiB |

栏目和阅读面板分别在测量前重置 `gfxinfo`。面板 10／20／30 轮为同一会话累计值，各 PSS 为采样时点，不能当作峰值。系统帧统计只反映此设备在本次轻量样例下的应用进程渲染，不用它断定 WebView、阅读定位或线程没有回归。当前样本量用于可比复测，未达到确定发布性能门槛的条件。

# 静读 Android UI 现代化改造设计需求

版本：1.0 · 设计交接稿 · 2026-11-25

## 1. 目标与范围

以已确认的现代文艺阅读风为全局基准，完成书库、云端、发现、设置、阅读控制及通用交互的统一设计。本文是产品与设计需求，供 Codex 基于源码制定实施方案，不是直接执行的代码改造指令。

依据：静读 0.1.5 测试版的 55 张截图及索引（界面提交 7f948b2，1080×2340）；用户已确认独立发现栏目、文艺阅读风及设置和阅读控制交互重组。参考图为生成式概念图，不是实际运行截图，图中示例数据、未来功能、页码、书签、最近访问等不代表现有能力。

## 2. 全局视觉规范

以下为根据已确认效果图拟定的设计参数，Codex 可根据实际组件和对比度测试微调，不得改变总体风格。

| Token | 浅色参考 | 深色建议 |
|---|---|---|
| Background | #F7F3EB | #20231F |
| Surface | #FFFCF7 | #292D27 |
| Primary | #526B53 | #B0C5A4 |
| PrimaryContainer | #DCE3CF | #394B36 |
| OnPrimary | #FFFFFF | #202D1E |
| Text | #252821 | #E8E9E1 |
| SecondaryText | #62665D | #B6BBAF |
| Outline | #D8D5CA | #53594E |
| Error | #A43E35 | #FFB4A9 |

- 采用统一主题 token，不在业务页面散落硬编码色值。现有 Theme.kt 据索引仅使用 lightColorScheme；全局深色属于新增外观能力，建议作为本次独立子阶段。阅读主题与应用主题独立。
- 标题可使用系统可用中文衬线字体，正文及功能文字使用系统无衬线；缺少衬线字体时回退，不强制引入大字体包。标题 26–30sp，分组标题 18–20sp，正文 14–16sp，辅助信息 12–13sp。支持系统字体缩放。
- 以 4dp 为间距基准，页面边距 16dp，列表间距 8–12dp，卡片圆角 12–16dp，封面圆角 6–8dp。点击区域至少 48dp；细分割线和轻阴影按需使用。
- 线性图标统一尺寸和笔画；选中态使用浅绿底和深绿图标，不能仅靠颜色表达状态。危险操作用独立错误色。普通文字对比度目标至少 4.5:1。
- 少量山水、植物插画只用于设置或空状态；不铺设纹理，不占用书库搜索结果空间。装饰素材须原创或有许可。
- 动画建议 150–250ms，支持系统减少动画及低动画模式；不增加模糊、重阴影等高开销效果。

## 3. 信息架构与导航

四个一级栏目：书库 / 云端 / 发现 / 设置。云端二级：百度网盘、WebDAV；发现二级：Z-Library，未来网络书源。当前未实现的网络书源、AI 翻译不得显示为可用功能，待独立需求上线再启用。

优先保留现有二级标签直达与滑动切换，不采用概念图中的云端入口卡片强制增加一级点击。云端及发现顶部标题和底部导航固定，只有内容区域参与二级滑动；一级切换只移动一级内容。各栏目保留搜索条件、滚动位置及已加载数据；返回键优先关闭弹窗、退出多选或返回子页。阅读器不显示主导航。系统返回手势、横向列表和分页不得互相抢占。

## 4. 页面与交互设计

### 4.1 本地书库

- 顶部大标题「书库」、书籍数量、搜索、网格/列表切换、更多菜单；搜索展开后保留筛选状态，清空关键词恢复原列表。筛选胶囊：全部、未读、在读、已读；排序保留最近阅读和按书名。
- 网格默认三列（按可用宽度适配），封面比例约 2:3，缺封面使用统一占位；书名最多两行，进度条与百分比并列，已读显示文字/图标。列表保留封面、书名、可用作者信息、文件大小、进度；无作者时不伪造。
- 点击直接阅读；长按进入现有多选模式，顶部显示数量、全选、取消及批量操作。移除与删除的原有语义必须明确区分，删除前确认。不得将长按改成只显示详情而破坏多选。
- 导入 FAB 保留，打开底部面板提供 EPUB 文件导入、扫描文件夹。系统选择器不重绘。导入失败展示原因、返回书架或可用的重试入口。空库展示导入按钮；无匹配展示清除搜索。继续阅读卡片不默认新增。

### 4.2 云端书库

- 标题「云端」，百度网盘 / WebDAV 标签固定；统一文件行、目录图标、文件大小及下载状态，路径过长可横向滚动或省略中间部分。保留刷新、返回上级目录、现有远端操作。
- 未授权/未配置分别展示原因及「去授权」「去配置」，网络失败展示重试；加载时保持布局稳定，已有数据刷新不清空列表。空目录与失败区分。
- WebDAV 书籍详情采用底部面板，展示实际名称、大小及现有元数据，主操作为下载/导入。远端删除确认明确影响远端文件，不混同本地移除。
- 云端下载结果、旧任务弹窗与下载管理统一视觉；是否共享任务数据模型由 Codex 审查，不能为了统一 UI 改写同步协议。

### 4.3 发现

- 标题「发现」，Z-Library 作为当前可用渠道；网络书源预留二级位置但未实现时隐藏。搜索是主内容，避免首页大幅插画、推荐轮播或额外入口页。
- Z-Library 保留搜索、语言及排序筛选，搜索后压缩顶部区域；结果采用封面、书名、作者、可用格式/大小及操作列表，数据缺失不编造。保留现有原生搜索失败时网页搜索入口及实际存在的热门书单回退逻辑（须源码核实）。
- 初始、加载、无结果、未配置服务器、请求失败、网页回退、下载及导入结果分别设计状态。网页容器保持返回、关闭和必要状态提示，不能改变已有下载链路。
- 后续网络书源页面沿用搜索结果列表、来源标识、下载进度及导入成功反馈；本期不实现书源解析、搜索聚合或 EPUB 生成。

### 4.4 设置首页与子页

首页采用分组列表，图标、标题、说明、右箭头；可在顶部放轻量插画，但不得挤占常用入口。设置子页使用统一返回标题栏、分组标题、开关、单选及表单。分类如下：

| 分类 | 迁移现有功能 / 设计边界 |
|---|---|
| 阅读偏好 | 默认字体、字号、行距、页边距、阅读主题、翻页模式及动画 |
| 外观与主题 | 应用主题、书架布局偏好、栏目滑动设置（实际归属由源码确认） |
| 同步与备份 | 书籍同步、自动进度同步、同步目标、上传任务、同步记录及诊断 |
| 书库与书源 | 百度授权、WebDAV 配置、Z-Library 设置、账号、服务器管理及默认偏好 |
| 语音朗读 | 后台朗读、Kokoro 模型管理及诊断（按构建变体和模型状态显示） |
| AI 与翻译 | 未来功能，当前隐藏 |
| 存储与下载 | 下载位置、下载任务入口；缓存清理仅在已有能力时显示 |
| 关于静读 | 版本及已有诊断/帮助信息 |

配置表单：标签常驻，凭据默认遮挡，保留现有保存/取消/验证语义；错误定位到字段或表单。Z-Library 服务器管理保留自动选择、列表、批量导入导出、恢复默认及配置导入导出。同步记录与上传队列保留空态、结果和实际可用操作。禁止因页面迁移改变配置键、默认值或清除用户凭据。

### 4.5 阅读器

- 沉浸态维持现有正文渲染、点击热区、翻页和滚动行为；不强制修改正文排版或添加纹理。进度、页码仅展示引擎可准确提供的数据。
- 点击正文中部展开工具栏：顶部返回、书名/章节、现有操作；底部进度滑块及目录、排版、主题、朗读、更多。再次点击正文或返回关闭面板；面板互斥，避免堆叠。
- 目录保留现有章节抽屉或等效独立面板，高亮当前章并滚动定位；点击跳转后关闭。书签/笔记仅在实际功能存在时显示，不新增虚假入口。
- 排版面板：字体选择及自定义字体导入、字号、行距、页边距，翻页模式及动画可归入更多排版项。概念图的段距、对齐若无现有能力不新增。调整立即预览，保留原有持久化范围与阅读定位。
- 主题面板：浅色、米黄、护眼、深色、夜蓝，使用真实颜色预览及选中标记；自定义主题或跟随系统阅读主题若未实现不纳入本期。阅读控制面板应适配当前阅读主题，避免夜间突然亮白。
- 朗读面板：现有引擎、音色、语速、开始/停止；暂停、前后跳转、音量仅在实际服务支持时显示。Kokoro 可用时才显示对应选项。后台电池引导保留直接朗读路径；系统通知权限由 Android 管理。
- 更多面板：阅读进度同步及其他已存在功能。同步弹窗清楚区分本机/云端进度和操作方向；不改变冲突策略。未来双语翻译预留入口但本期隐藏。

### 4.6 通用弹窗与任务状态

普通选择、筛选和详情优先底部面板；不可逆删除、覆盖及关键确认使用居中对话框；短反馈使用 Snackbar，长任务使用持久任务列表。表单键盘弹出后主操作可见，支持系统返回与无障碍焦点。任务状态统一为等待、进行中、成功、失败等实际状态；取消、重试、清空历史仅在底层支持时提供。不得将下载成功误标为导入成功。

## 6. 实施约束与建议阶段

Codex 首先审计当前分支、Compose/主题实现、导航状态、设置键及构建变体，输出实际文件级方案、组件复用方式、风险、测试和回滚策略，交由 ChatGPT 评审后再执行。建议阶段：A 全局主题和通用组件；B 四栏目及本地书库；C 云端、发现和下载；D 设置分类迁移；E 阅读控制；F 深色、适配和全量回归。阶段可根据源码依赖调整。

不得修改 EPUB 原始内容、CFI/阅读定位、KOReader 同步协议、数据库及书籍标识、下载协议、TTS 引擎逻辑，除非另行审批。测试包与正式包隔离；不清理正式版数据、不泄露账号或凭据。每阶段提交前后截图、测试结果、已知问题及回滚点。

## 7. 验收

- 55 张基准截图对应的所有实际功能和状态均有新版对应项；附录提供逐项追踪表。未采集的真实状态须在可用测试环境验证，不能以概念图代替。
- 四个一级栏目正确，二级滑动不带动固定标题及一级导航；切换、返回、旋转或进程恢复不丢失应保留的状态。
- 本地导入、搜索、筛选、排序、多选、删除、打开阅读均回归；云端授权、配置、下载、导入、同步及错误恢复均回归。
- 阅读主题、字体、进度、目录、翻页、系统 TTS、可用 Kokoro、后台权限及同步回归；改造前后同一书籍定位保持一致。
- 1080×2340 基准设备以及窄屏、大字体、深色、低动画模式验证，无裁切、重叠、低对比度及不可点击控件。性能以改造前实测为基准，检查启动、滚动、切换、内存及阅读翻页，无明显退化。
- 验收交付：新版截图索引、功能映射、测试报告、未完成项及风险说明。

## 8. 已知限制

原始素材未覆盖真实百度授权后书库、Z-Library 成功搜索/网页下载、统一下载历史和覆盖确认、可访问书签管理、已部署 Kokoro 音色、全局深色主题。本文对这些状态提供设计规则，不声称已验证。概念图只覆盖核心页面；其他子页和异常态以文字规范为设计交付，不是逐屏高保真原型。实际实现成本和组件结构待 Codex 源码审计。

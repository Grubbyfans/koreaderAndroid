## 1. 改造范围与业务边界

以暖纸白、低饱和苔绿、少量山水植物点缀和中文衬线标题统一应用外壳。采用概念图的大标题、书封布局、分组设置、短标签阅读面板。云端保留百度网盘与 WebDAV 二级标签直达，发现打开即进入 Z-Library 搜索。概念图中的入口卡片、最近访问目录、热门搜索词、账号容量、书籍和进度均为示例数据。无业务来源的元素不进入页面。

改造范围覆盖 Compose 界面、导航状态归属、设置页面组织和现有业务状态的展示映射。保留 EPUB 文件和格式校验、WebView/JS 桥协议、CFI/XPointer、KOReader 进度与书库协议、Room 表、下载和中断恢复机制、账户存储、朗读服务及通知。继续使用独立测试包 `com.yuezhou.reader.tts.test` 做安装验证。正式包 `com.yuezhou.reader` 使用现有构建和签名配置。

## 3. 主题与组件复用

### 3.1 应用主题和阅读主题

- 由 A/`Theme.kt` 继续持有 Material 3 入口，建议拆出 `ui/theme/` 保存色板、字号、形状和间距。先迁移 `YuezhouColors` 的调用到主题色或语义 token，再打开全局深色。优先迁移 Scaffold、导航条、页头、卡片、输入框、菜单、表单、Snackbar 与系统栏；排查局部硬编码、图标默认 tint、禁用态以及弹窗窗口底色。
- 浅色以 `#F7F3EB / #FFFCF7 / #526B53` 起步，深色以 `#20231F / #292D27 / #B0C5A4` 起步。分别定义背景、表面、强调、文本、描边、错误及对应前景，实际对比度不过关时调整 token。普通文本至少 4.5:1，选中状态附文字、勾选或可访问语义。采用 4dp 间距基准、16dp 页边距和至少 48dp 触控；标题 26–30sp，提供中文衬线回退，功能文字保持系统无衬线。避免把大字体或增量字体文件并入 APK。
- 全局主题建议使用新增纯 UI 偏好 `app_theme_mode`，默认浅色，提供浅色、深色及跟随系统。现有 `reader_settings.theme` 仍独立保存阅读主题，继续采用实际的浅色、米黄、护眼、深色、夜蓝。阅读控制区使用当前阅读主题派生的本地色板。切换应用主题不写阅读偏好，切换阅读主题不改应用主题。正文实际颜色核对 A/`ReaderActivity.kt` 的主题映射及 `app/src/main/assets/reader/` 中 Web 端色板；预览用同一实际色值，首版保持正文样式。
- 应用主题系统用独立主题 ID 和完整 token 集支持后续扩展。本期只提供文艺浅色、深色和跟随系统，首次启动默认文艺浅色。跟随系统只改变应用外壳的配色。
- 普通 UI 动画以 150–250ms 为目标。系统关闭动效的优先级高于应用 UI 动效设置，关闭时采用即时状态切换，落页回调和确认操作仍执行。栏目滑动开关及阅读翻页动画继续各自独立配置，应用 UI 动效设置不改写阅读翻页偏好。
- 插画限设置首屏或空态，原创或有许可；大字体、窄屏和横屏收起装饰。底栏、二级标签、WebView 顶部和底部面板统一校验系统栏、键盘及手势 inset，避免重复应用 padding。阅读进度显示准确的百分比与章节，不显示概念图的固定总页码。

### 3.2 全局视觉规范与实际验收

两张已确认的概念图共同作为视觉基准。阶段 A 用真实页面验证暖纸白背景、苔绿强调、中文衬线标题、书封节奏、线性图标与设置分组的统一效果。Material 3 用于交互与无障碍基础，页面层级、布局和组件外观按下表落地。

| 项目 | 实施规格与检查点 |
| --- | --- |
| 字体与字号 | 栏目大标题 26–30sp，分组标题 18–20sp；标题优先可用中文衬线，缺字或不可用时回退。书名与功能正文 14–16sp，辅助信息 12–13sp，保持可读的行高。系统字体放大时允许换行、减列，不压缩文字。 |
| 间距与圆角 | 4dp 为间距基准，页边距 16dp，列表间距 8–12dp，主要点击区域至少 48dp。卡片圆角 12–16dp，封面 6–8dp，筛选和导航选中背景使用胶囊形。 |
| 图标与线条 | 功能图标统一 24dp 画布和视觉笔画，图标按钮提供可访问名称。分组和列表使用细分割线或留白表达层级，分割线使用描边 token。危险操作使用独立错误色和明确文案。 |
| 阴影与装饰 | 常驻列表优先使用表面色和留白，轻阴影仅用于浮动操作、浮层等需要区分高度的组件。不使用重阴影和模糊。插画限设置或空态，窄屏或大字体时让位给内容。 |
| 组件状态 | 统一默认、选中、按下、焦点、禁用、加载、空态、错误和成功反馈；以颜色配合文字、图标或可访问语义传达状态。普通文字至少 4.5:1，浅深色分别核对。 |

| 组件集 | 采用方式 |
| --- | --- |

## 4. 导航与状态方案

### 4.1 路由和手势

1. 演进 `ShelfPage.kt` / `ShelfNavigator.kt`。一级用稳定 ID `library`、`cloud`、`discover`、`settings`，子页以稳定书源 ID 或设置路由标识。保留 `shelf.local` 和旧 `cloud.<id>` 的读取兼容。原 `cloud.zlibrary` 恢复到发现；百度、WebDAV 保持归属；空或未知 ID 回退同栏目首个可用源，其次栏目空态，最后书库。新版本写入可独立兼容的导航键，旧键保留供回切读取；不以枚举序号、列表下标或中文文案做持久化定位。
2. 复用现有 Compose Pager，先做分层手势原型，保留一级和二级横滑。外层包含四个一级内容容器；二级滑动只移动二级内容，一级页头、二级标签及底部导航始终固定。云端保留百度网盘和 WebDAV 标签直达，发现默认进入 Z-Library 搜索，单源时不绘制占位标签。每次独立手势确定唯一所有者，组内可滑方向归二级；二级到达边界并结束本次手势后，下一次独立向外滑动可切换一级。同一手势禁止从二级交给一级。若同轴嵌套发生冲突，先提交原型验证报告，附设备录像、手势序列、落页结果和备选方案，经评审后调整，不擅自取消任何一级或二级滑动能力。底栏点击始终可直达一级。
3. 请求只记录意图和目标 key。成功落页后原子提交一级和有效书源，业务只观察提交后的业务路由。中途回拖、快速连续点击、列表重排或动画取消不得提交中间页。显式导航只提交最终目标。选中插值保持在二级栏局部，无联网、下载、刷新或读取凭据副作用。将 A/`MainActivity.kt` 中仅限 `Tab.云端` 的落页业务、顶栏动作、返回条件逐项迁移：云端菜单只服务云存储，发现菜单继续开放 Z-Library 账户、热门和网页回退入口。
4. `SwipeBlockRegistry` 继续服务搜索输入、横向列表、详情、多选、下载及宿主弹窗。避免根 Pager 和内部组件同时抢系统返回边缘。返回顺序为系统权限或键盘、最上层弹窗/面板、退出多选或搜索编辑、当前子页返回、一级返回书库、退出。发现的清搜索与详情返回沿用现有优先级。设置及下载记录正常的来源路由；下载进入阅读器后回到任务，外部 EPUB Intent 沿用原入口及任务栈。
5. 设置子页建议使用单一类型化 `SettingsRoute` 栈，替换互相组合的布尔开关。深链到服务器管理先到书库与书源 → Z-Library 设置 → 服务器管理，逐层返回。无需引入全局 NavHost；如果阶段 B 评审另选 Navigation Compose，先在设置子图试用，保留宿主路由的单一所有者。

### 4.2 状态和恢复契约

| 状态 | 所有者及恢复 |
| --- | --- |
| 已提交一级/书源、每栏目上次落页及设置子路由 | 导航器、可保存的轻量 ID。进程重建按兼容键解析；模态确认、手势进度、提交中的命令不自动重放。云端与发现分别记录上次源，避免发现覆盖 `last_cloud_provider`。核对 VM 默认参数调用点，迁移后重要动作显式传 providerId。 |
| 本地查询、筛选、排序、布局、滚动 | 保留 `rememberSaveable` 的轻量输入状态和 `library_ui` 的布局、默认滚动锚点。以书籍 ID 加偏移为优先恢复依据，失效时夹紧索引。筛选临时滚动与默认书架分离；多选只操作有效书籍 ID，退出清理。 |
| 云端与发现数据 | `OnlineLibraryViewModel` 继续按 provider 管理；相邻页预组合不请求。保留草稿/已提交查询、语言、排序、页游标和错误，旋转/页切缓存于 VM；进程重建只恢复无凭据的查询及滚动，按现有缓存或一次显式受控重载恢复数据，避免重新下载。云端列表缺少同一 provider 的过期回写保护，既有竞态纳入测试。若需修复先单列、评审并独立提交，避免混在视觉迁移。 |
| 阅读文档、位置、朗读计划 | `ReaderActivity`、WebView、现有 DataStore 和服务持有。工具栏与面板仅保存临时选中项。系统主题变更、旋转和面板切换不可销毁正在读取的 WebView 或旁路位置保存。 |
| 凭据、下载任务、上传队列 | 现有存储/服务持有。UI 不缓存或恢复密钥、Token、密码及授权链接。下载恢复由管理器负责，上传队列与旧任务按当前作用域呈现，不在改造时承诺额外持久化。 |

## 5. 页面改造清单

### 5.1 本地书库

从 A/`MainActivity.kt` 移出书库展示（建议 A/`ui/library/LocalLibraryScreen.kt`），宿主保留稳定业务调用与事件转发。大标题展示实际可见书总数，搜索展开保留筛选，清除输入恢复当前筛选下列表。条目使用 `bookId`，默认可容纳三列时保持三列，窄屏、大字体动态减列。封面约 2:3，书名最多两行，进度及已读语义取自已有 `ReadingFilter`，不由文案重新定义阈值。若列表需要作者，复用 `LibraryStore.shelfAuthors`，以书籍版本、URI/文件元信息为失效条件做有界内存缓存，在后台按可见项或搜索批次读取，权限丢失或无作者时只展示已有元信息。
 
导入 FAB 打开方式面板，连接已有选择器与扫描回调，保留重名位置选择。外部导入走 `OpenEpubActivity`；失败按真实原因展示可用操作。点按继续直开，长按进入多选。移出书架、永久删除本机文件、删除远端三者分别提示影响；不为列表新增独立详情页。保留已移除书籍恢复、全选范围、阅读中书籍保护及文件权限提示。

### 5.2 云端、发现和下载

- A/`ui/online/OnlineLibraryScreen.kt` 先分出云存储正文和发现正文的宿主入口，复用现有 `CloudBookshelfContent`、`CatalogLibraryScreen` 和 `BookDetailScreen`。云端提供网格/行式信息时保留已知大小与本机状态。未授权及未配置入口跳到相应设置表单，完成后返回原书源并刷新一次。WebDAV 详情移至面板，保留关闭、打开、下载及远端删除确认，防止在过期书源状态下操作。
- 发现首屏就是搜索。保留语言、排序、EPUB 约束、列表/网格已有能力、初始/加载/无结果/失败/重试、结果加载更多、热门回退与网页入口。热门来自适配器 notice 或显式动作，标注为非关键词结果。结果无头像、作者、封面或大小时依已有字段呈现。保留图中「更多」的视觉位置，未来网络书源与 AI 翻译不显示。网页外壳只修改 A/`web/ZLibraryWebActivity.kt` 的可见标题、状态和关闭按钮；维持独立进程、信任策略、WebView 会话、导航控制以及系统下载交接。

### 5.4 阅读控制

- 阅读 Activity 持有 WebView 和所有位置、同步及服务回调。建议新增 A/`ui/reader/ReaderControls.kt` 与子面板组件，以单一状态表达沉浸、工具栏或当前子面板。目录、排版、主题、朗读和更多互斥；返回从子面板到工具栏，再到沉浸阅读。确认与系统权限位于更高返回层。普通面板优先使用可滚动的限高布局，尽量保留正文可见区域。目录选择后跳转并关闭。保留中点热区、亮度、页边返回手势、顶部导入入口和应用内返回。
- 阅读面板开关、主题切换及其他 UI 状态变化不得引发非必要的 WebView 重建、文档重载、位置漂移或额外同步。保持文档宿主、Compose 标识及生命周期回调稳定；阅读主题变化沿现有设置桥更新。记录 WebView 创建次数、EPUB 打开次数、当前阅读锚点和同步调用次数作为验收证据。
- 排版提供字体和自定义字体管理、字号、行距、页边距、翻页方式和动画，沿用单位和取值。即时预览在原生控件先反馈；推送正文的频率和时机以现有松手/离散变更为起点。确需拖动实时重排时先做独立定位试验，连续拖动期间不可覆盖已保存位置。进度滑块释放才触发 `goToFraction`，保持只跳转一次。目录沿用现有层级和活动章节锚定。书签、笔记、段距、对齐和正文新增功能不进入本期。
- 朗读继续消费服务确认的状态和高亮，保留直接朗读、电池引导、系统通知和音色选择。语速使用现有命令，音色或引擎变更先保存再走现有重启策略，停止可取消正在准备的任务。若接入媒体服务已有暂停/前后句，先验证服务状态与界面按钮在后台、锁屏、切章和进程回前台一致，再开放控件。正式版只提供已装配的系统 TTS。
- 更多保留阅读进度同步。显示本机和云端位置、时间与上传/应用方向，保留应用后撤销与现有自动开关语义。不得将打开弹窗或切换面板当作同步触发，避免跨端覆盖。同步落点仍通过现有 CFI/XPointer 转换和确认保存。

## 8. 风险控制、回滚与独立评审问题

| 风险 | 防线与回滚 |
| --- | --- |

| 无法用真实服务验证 | 阶段 0 指定测试账号和端点，先用协议样例用于确定性回归，再补真机闭环。没有真实证据的闭环不得标为已验收。 |

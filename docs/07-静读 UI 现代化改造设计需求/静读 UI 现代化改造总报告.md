## 剩余验收与回滚

- 百度真实账号授权、Z-Library 合法隔离账号搜索到下载、KOReader 跨端双向实际落点、Kokoro 模型及真实播放仍需补测。协议与 Web 自动化结果仅覆盖其实际测试内容。
- 100、500、1000 本原创测试 EPUB 已生成，生成脚本随阶段 B 提交。三种规模均在隔离包中完成书架打开和滚动，批量管理与长时性能仍需专项验证。
- 保留阶段 A.1 已确认的技术债务：书库与云端 PSS、首屏可交互耗时、阅读器重进时 WebView 对象和内存变化，以及 WebView 沙箱进程长期稳定性。低版本 Android、窄屏、放大字体、多设备和长时间内存需持续验证。
- 暂未开放 TTS 暂停、恢复、前后句及独立音量入口，待现有服务能力验证。系统 TTS 真机回归覆盖起停与状态，锁屏续读、音频可懂度与高亮位置仍需专项验收。
- 单点回滚用 `git revert <提交>`。跨阶段回滚从 F 到 B 逆序应用，并评估独立缺陷修复是否保留。在当前独立测试包的基础上需要回退 UI 时，优先从 `7ec4a0d` 或目标节点构建更高 versionCode 的同签名测试包，避免卸载导致数据丢失。生产发布需另行确认。

## 阶段 B 性能复测

在同一手机上使用阶段 A 和阶段 B 隔离包。四本相同 EPUB 和封面、相同书架入口、60 Hz、`cmd package compile -m speed -f`。交错执行 12 对有效冷启动，A 和 B 的电池温度分别为 35.9–37.7°C、35.9–38.2°C。使用 A.1 的相同探针口径。书库可交互时间是数据加载完成后的两帧回调代理。PSS 是主进程在固定场景的单次快照，不包含所有 WebView 沙箱进程。证据包内含每次启动的 Activity 和探针原始日志、CSV、按场景分类的 meminfo，以及每 10 轮面板开关、阅读退出和重进的采样。

| --- | ---: | ---: | ---: | ---: |
| Activity 启动中位数 | 256 ms | 285 ms | 291 ms | +2.1% |
| 首帧绘制中位数 | 149.80 ms | 189.46 ms | 196.30 ms | +3.6% |

B 的 Activity 中位数为阶段 0 历史值的 113.7%，在 120% 参考线内。书库可交互代理为历史值的 127.6%，书库 PSS 为历史值的 120.5%，超过 120% 和 110% 参考。换轮后，阶段 A 的同场书库可交互代理也从 A.1 实测 335.63 ms 变化到 408.23 ms，因此全局基线用于识别风险，同轮 A 用于判断增量。云端相对 0 的历史值为 106.4%，本轮相对 A 则增加 11.0%。书库和云端的单次 PSS 增量需要多轮分类采样再定位。现有结果无法归因于字体或判定泄漏。未执行最终 F APK 的独立配对性能测试。

第 1 次到第 10 次重开阅读器，A 的单次 PSS 从 255.53 到 272.43 MiB，B 从 256.71 到 283.29 MiB。回到书库并闲置 10 秒后，A 为 229.05 MiB，B 为 235.86 MiB。两组均验证了重复进出，主进程占用均随重开增加。结果保留为长时间 WebView 跟踪事项。

## 最终测试版专项

- 屏幕抽样确认浅色暖纸 RGB 247/243/235，深色表面 RGB 32/35/31，深色重启后保持。实测切换减少界面动画，保留开启及恢复两张真机图。跟随系统选项已操作，系统从浅色切换到深色的矩阵仍待补测。
- WebDAV 本机测试夹具中，《海边散步指南》下载前显示「尚未下载到本机」，下载完成后重新打开详情显示「已在本机书库」。只读核对本地书库快照中该条目为 ready 且 EPUB 文件存在。本地书架优先展示 EPUB 元数据书名，夹具复用《沿江手记》的 EPUB，因此本地显示名不同于 WebDAV 的条目名。证据包含书名映射和下载后本地七本书的首屏，首轮用例按远端标题匹配的断言被本地书名复核取代。
- 校验独立测试 APK 的 Android Debug 签名并覆盖安装成功。WebDAV 本地测试服务与 ADB 端口映射已关闭，测试包保留夹具配置及样例。正式包 com.yuezhou.reader 的已装版本及更新时间保持 0.1.5、2026-11-25 22:46:08。

## 大书库验证

阶段 B 独立对照包分别加载 100、500、1000 本原创 EPUB，均显示书架并可纵向滚动，截图及 meminfo 已归档。测试数据未导入常用测试包或正式包。100 本与 500 本的单次可交互代理分别为 471 ms 与 830 ms。1000 本首次超过常规探针采集窗口，延长日志等待后补测为 1678 ms。三种规模只有单次有效代理样本，不能用作稳定阈值。样本以原创文本和 EPUB 元数据为主，未覆盖大批量真实封面。阅读器模块的书库快照在逐书映射时重复读取、解析同一书名映射文件，是大书库后续排查点，当前没有隔离对照能量化其耗时比例。

## 2. 主题 Token 与组件规范

| 语义层 | 已实施值／规则 |
| --- | --- |
| 色板 | Background `#F7F3EB`、Surface `#FFFCF7`、Primary `#526B53`、OnPrimary `#FFFFFF`、PrimaryContainer `#DCE3CF`、OnPrimaryContainer `#344E36`、Text `#252821`、SecondaryText `#62665D`、Divider `#D8D5CA`、Outline `#858879`、Error `#A43E35`。Divider 用于低强调分隔，交互及焦点需用可识别描边。 |
| 字体 | 栏目 26sp／34sp，Headline Large 30sp／38sp，分组 Title Large 20sp／28sp、Title Medium 18sp／26sp。标题复用中文衬线字体，功能正文和标签继续使用系统 sans-serif。 |
| 形状及节奏 | 以 4dp 为步长，常用间距 4／8／12／16dp，页边距 16dp，封面圆角 8dp、卡片 16dp、全局较大浮层 20dp。网格和列表封面均取 2:3。 |
| 搜索和筛选 | 暖白输入框、16dp 圆角、聚焦描边和可访问清空操作。筛选选中使用浅绿表面与深绿前景，沿用原组件选中语义。 |
| 导航和任务状态 | 一级导航使用 24dp 图标与文字标签，选中色板来自主题，底栏无额外色调高度。空态、禁用、错误与弹窗继承统一角色，现有任务状态和值仍由业务层提供。 |
| 书封与进度 | 书名最多两行；同一进度条组件展示百分比，满进度显示「已读」。继续使用已有封面、占位资源和真实进度。 |
| 动效与深色 | 不新增页面动效、不变更现有持续时间和阅读翻页配置。仅启用应用浅色；阅读正文仍由自身主题控制。 |

纸色上的正文和辅助文字对比度分别为 13.51:1、5.30:1。白字在主色上为 5.85:1，选中文本在选中容器上为 6.96:1，错误文字在表面色上为 6.18:1。数值按纯色 token 计算；未替代逐控件的无障碍验收。

## 5. 性能复测与基线对照

沿用阶段 0 的 SM-S9360、1080×2340、独立测试包、无线 ADB、相同样例和操作脚本。书库保留阶段 0 下载样例，因此当前比初次测量多一项。本轮为覆盖安装后的采样，ART 热身、缓存和调度不同，PSS 为单点快照。先看数据偏差，再通过重复配对测量判断成因。

| 场景 | 阶段 0 | 阶段 A |
| --- | --- | --- |
| 进程冷启动 · Activity TotalTime | 277, 211, 219, 213, 220 ms，中位 219 ms | 560, 515, 512, 511, 516 ms，中位 515 ms |
| 栏目点击36次 | 1751 帧 · 卡顿 73 (4.17%) · P95 12ms · 157.9 MiB | 1782 帧 · 卡顿 58 (3.25%) · P95 14ms · 186.9 MiB |
| 云端二级往返10轮 | 1652 帧 · 卡顿 100 (6.05%) · P95 14ms · 184.3 MiB | 1655 帧 · 卡顿 88 (5.32%) · P95 13ms · 210.7 MiB |
| 阅读循环前 | 无帧数据 · 253.0 MiB | 无帧数据 · 314.7 MiB |
| 阅读面板10轮 | 504 帧 · 卡顿 23 (4.56%) · P95 17ms · 275.9 MiB | 503 帧 · 卡顿 22 (4.37%) · P95 13ms · 317.3 MiB |
| 阅读面板20轮 | 1007 帧 · 卡顿 46 (4.57%) · P95 17ms · 271.9 MiB | 1008 帧 · 卡顿 44 (4.37%) · P95 13ms · 313.3 MiB |
| 阅读面板30轮 | 1507 帧 · 卡顿 68 (4.51%) · P95 16ms · 272.3 MiB | 1514 帧 · 卡顿 65 (4.29%) · P95 14ms · 313.5 MiB |
| 阅读面板闲置5秒 | 1507 帧 · 卡顿 68 (4.51%) · P95 16ms · 261.5 MiB | 1514 帧 · 卡顿 65 (4.29%) · P95 14ms · 302.6 MiB |

**性能评审结论：待复测。** 最终版冷启动中位数 515 ms，相比 219 ms 基线增加约 135%。阅读面板 30 轮 P95 从 16 ms 改善到 14 ms，但闲置 PSS 高于基线。尚未定位冷启动和 PSS 偏差的原因，建议在评审决定后用同入口、数据快照和热状态交错测试 APK，并用启动追踪定位主线程和首帧耗时。

首轮候选（386ceac）在主线程使用标题字体，冷启动中位数为 558 ms。7ec4a0d 将字体加载移入 IO 并在进程内缓存，上表以最终版真机数据为准。冷启动止于 Activity 启动完成，未代表可完整阅读的时间。阅读面板帧统计为每轮累计。本报告保留全部实测值；超过基线警戒的观测须做配对复测，经评审再决定处理，当前不将性能门禁标为通过。

## 6. 已知差异、后续门禁与回滚

- WebDAV 下载后本机提示滞后仍列为阶段 0 基线现象，阶段 C 前复核。云端竞态于阶段 B 前用可控时序确认，设置并发写入于阶段 D 前确认，若证实均独立修复。
- 阶段 B 前的 100／500／1000 本原创 EPUB、阶段 C 前的百度与 Z-Library 合法隔离账户、阶段 E 前的 KOReader 对照与 Kokoro 模型、阶段 F 的多设备及长时间内存均保留原门禁。涉及远端授权由用户手动完成。
- 测试版覆盖升级后正式包仍为 0.1.5，安装时间未变。回滚时撤销阶段 A 代码提交，再以现有测试签名构建可覆盖的较高 versionCode 测试 APK，保留书库与配置。未执行回滚安装。

## 4. 改造前后 UI 对比

改造前为「书库页内 本地/云端 分段 + 书源 chips + 悬浮刷新」，云端无独立一级入口；Z-Library 头部占三行筛选并常驻登录状态行。

| 对比项 | 改造前 | 改造后 |
| --- | --- | --- |
| 底部导航 | 2 项：书库 / 设置 | 3 项：书库 / 云端 / 设置 |
| 云端入口 | 书库页内分段切换 | 独立一级页，独立顶栏 |
| 云端操作 | 悬浮「刷新」+ 顶栏下载 | 顶栏「下载任务 + 更多」；下拉刷新 |
| 书源切换 | 独立 chips 行 | 等宽紧凑分段 Tab |
| 搜索区 | 56dp 输入框 + 搜索 + 网页搜索按钮 | 40dp 输入框 + 图标搜索 + 「网页」 |
| 筛选 | 语言行 + 排序行 + 格式文本 | 单行摘要 + 底部弹窗（格式固定说明） |
| 账户/额度 | 页面常驻「正在读取登录状态…」 | 收进更多菜单，按需读取 |
| 热门降级提示 | 列表上方固定文本 | 列表首项提示条，随内容滚动，带重试/网页入口 |
| 滚动位置 | 切页回到顶部 | 按索引 + 偏移量恢复 |

## 5. 未解决问题与风险

1. 本地书库滚动恢复仅在单本书环境验证，多书分页场景需复验。
2. 热门书单接口为服务端固定单页，无法分页；服务端不可达时只能错误提示 + 网页搜索。
3. 关键词搜索是否被拒由服务端返回决定，不同镜像站点行为可能不一致。
4. 搜索结果与筛选条件不跨进程保存（方案范围内）；重启后需重新搜索。
5. Lint 仍有 52 条既有 warning（DefaultLocale、废弃图标等），非本次改动引入。
6. 测试版包名独立，正式版数据不受影响；如需正式发布需另打生产包。

## 2. 实现说明

### 2.1 页面结构

```text
云端书库（顶栏：下载 + 更多）
├─ 紧凑书源 Tab：百度网盘 / WebDAV / Z-Library
├─ 搜索行：紧凑输入框（40dp） + 网页
├─ 筛选摘要：全部语言 · 最佳匹配 · EPUB      列表/网格
└─ 书籍区
```

固定区域由原来的搜索行 + 语言行 + 排序行 + 额度行（约 180dp）压缩为约 84dp，首屏书籍区明显增大。

### 2.2 搜索工具栏

- 使用 `BasicTextField` + `Surface` 自绘 40dp 输入框，避免 Material `TextField` 56dp 最小高度。
- 支持键盘搜索键、右侧搜索按钮；提交后自动收起键盘并清除焦点。
- 输入为空时搜索提示“请输入书名、作者或 ISBN”。
- 「网页」入口保留；网页搜索只传服务器地址与当前输入关键词。

### 2.3 筛选弹窗

- 语言、排序统一放入 `ModalBottomSheet`，格式固定显示“EPUB（固定）”，不再提供无实际作用的格式控件。
- 草稿态编辑，点「应用」才生效；「重置」恢复全部语言 + 最佳匹配。
- 已搜索过：应用筛选后按**已提交关键词**发起一次新搜索（取消旧请求，走 `requestSeq`）。
- 未搜索过：只更新筛选条件，不发请求。
- 摘要行始终可点击，显示当前语言、排序与格式。

### 2.4 账户菜单

- 移除 Z-Library 页面常驻额度文本。
- 云端「更多」菜单新增：
  - `Z-Library 账户`：显示 `quotaText`；
  - `账户管理`：跳转现有 Z-Library 设置页；
  - `刷新云端书库`；
  - `网页搜索`。
- 打开菜单时调用一次 `loadQuota()`，避免页面切换时重复读取。

### 2.5 展示模式

- 网格/列表切换按钮移至筛选摘要行右侧。
- 两种卡片复用现有实现，切换不发起接口请求。
- 默认网格；持久化在阶段 D 实现。

## 1. 本阶段实现的功能

- **手动上传入口**：统一下载管理页中，**仅已完成（已导入）**的下载任务显示「上传云端」按钮；点击后选择百度网盘 / WebDAV 中的一个或两个目标，确认后开始上传。没有自动上传，不改变「稍后阅读」行为。
- **双目标独立结果**：对每个所选目标单独调用现有 `CloudSync.pushLocal()`，分别记录「已上传 / 失败 / 已跳过（未配置）」及消息；一侧失败或异常不会传播到另一侧，也不回滚另一侧已完成的上传。
- **结果反馈**：上传完成后弹窗逐项展示两个云端的结束状态与消息；未完成的完整提示保留在结果中（例如「结果未知，请检查云端」不会误标为成功）。
- **兼容边界**：复用既有正文、封面、`library.json` 索引、`bookId`、目录结构与待发布回执机制；未创建第二套云端目录，未修改进度协议。阅读界面的进度上传/下拉仍是原有 `CloudSync.uploadLocalProgress()` / `fetchRemoteProgress()` 链路，KOReader 看到的书目与进度路径不变。

## 6. 已知问题及风险

1. 本次未用真实百度/WebDAV 账号做端到端上传实测；桥接逻辑由单测覆盖，真实网络结果待设备与凭据就绪后验证。
2. 上传过程不支持单独取消（沿用 `pushLocal` 现有行为）；关闭应用会中断上传，未完成发布由既有回执机制在「补全待发布」中恢复。
3. 目标 availability 不在选择弹窗中预检，未配置的目标在结果里标注「已跳过」；这样两侧凭据状态不会在选择阶段互相干扰。

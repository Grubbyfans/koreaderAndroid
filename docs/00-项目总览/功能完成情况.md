## 二、已完成功能明细

### 1. 工程与协议基础（P0）

- Gradle 9.7.0 / AGP 9.3.1 / Kotlin 2.4.20 / Compose BOM 2026.09.00 / KSP，compileSdk 37 / targetSdk 36 / minSdk 26。
- 多模块结构：`:app`（UI）、`:core`（协议 + 位置转换）、`:reader`（书库/导入/WebView）、`:speech`（预留 TTS）。
- 协议模型对齐 BaiduPanSync schemaVersion=2：`LibraryCatalog`、`CloudProgress`、`CoverFile`、`BookNames`，双向编解码 + 严格校验（`ProtocolValidation`）。

### 2. 精准定位核心（P1）

- `PositionCodec`：实现 CFI ↔ XPointer 双向转换，配合 `DomNode`、`PositionModel`、`XPointerCodec`、`CrengineWhitespace`。
- 覆盖单测：`PositionCodecTest`、`ProtocolCodecTest`、`FixtureTest`，验证位置编解码与协议编解码正确性。
- **运行时桥接（JS 侧）**：`reader/xpointer.js` 在 foliate-js 真实 DOM 上完成 CFI↔XPointer 转换（复用 `view.resolveCFI`/`view.getCFI`/`CFI.fromRange`/`CFI.toRange` + CREngine 空白折叠规则 + XPointer 编解码），经 `bridge.js` 暴露 `cfiToXPointer`/`xPointerToCfi`，`ReaderWebView` 异步调用，接入阅读页「进度同步面板」的上传（CFI→XPointer）与应用（XPointer→CFI）双向流程。

### 3. 本地 EPUB 导入与书库（P3）

- **导入**：系统文件选择器选 EPUB → `EpubImporter` 落盘至 `files/epub/`，提取封面与书名元数据，登记书库。
- **封面提取**：`CoverExtractor` 解析 OPF/container 定位封面，保留彩色并编码为 WebP/JPEG（≤200 KiB）并解析 `<dc:title>` 书名。
- **书库存储**：`LibraryStore` 管理 `library.json`（复用协议，`title` 恒等于 `bookId` 保持兼容）、封面、进度、显示名映射（`display_titles.json` 单独存真实书名，不破坏协议）。

### 4. 阅读闭环（foliate-js + WebView）

- **阅读内核**：Android WebView + foliate-js（本地 assets），`ReaderWebView` 封装加载/桥接/事件。
- **JsBridge**：`addJavascriptInterface` 注入一次（loadUrl 前），封装打开书、翻页、目录、排版设置、位置回调。
- **进度保存/恢复**：`relocate` 事件 300ms 去抖保存；`onStop/onPause` 立即 flush；重开书用 CFI 恢复位置（`goTo`）。

### 5. 阅读页交互（微信读书式）

- **单击三分区**：左 1/3 上一页、右 1/3 下一页、中间 1/3 呼出/收起面板（手动判定单击，位移 ≤12px 且 ≤300ms）。
- **上下滚动跨章节**：改 foliate-paginator 边界检测，滚到底自动进下一章、滚到顶回上一章。
- **翻页锁修复**：`#turnPage` 加 `finally` 释放锁，解决翻页异常导致后续点击翻页失效的卡死问题。
- **沉浸式面板**：顶部返回 + 书名 + 章节号，底部进度条 + 目录/设置按钮。
- **目录抽屉**：章节列表（序/章），点击跳转。
- **排版设置**：字号、行距、边距、主题（浅色/羊皮纸/深色）、翻页模式（左右/上下），经 `ReaderSettings`（DataStore）持久化。

### 6. 书架与全局 UI（微信读书配色）

- **书架网格**：3 列封面卡片，显示真实书名 + 阅读进度条。
- **封面占位**：无封面书籍用书名文字 + 按 bookId 哈希的稳定渐变色底。
- **底部导航**：书库 / 最近阅读 / 设置 三个 tab，最近阅读按阅读时间倒序。
- **移除书籍**：长按进入管理态 → 多选（右上角勾选圆点）→ 顶栏「已选 N 项 / 全选 / 删除」，删除后彻底清理正文/封面/进度/显示名。
- **统一主题**：`Theme.kt`（`YuezhouTheme`），品牌青绿 `#07C160` + 米白底 `#F7F7F7`，全局套用。
- **删除二次确认**：删除前弹窗列明书名与「正文+进度一并移除、不可撤销」范围（§12.2）。
- **删除撤销**：软删除 + Snackbar 撤销，超时才真正落盘移除。
- **封面解码优化**：后台线程解码 + 限尺寸降采样（targetPx=512），避免主线程卡顿。
- **滑块去抖**：进度/字号/行距滑块松手才生效，避免拖动连续重排卡顿。
- **Material NavigationBar**：底部导航改用标准 NavigationBar + 图标 + 无障碍语义。
- **设置页可操作**：主题/翻页模式/字号/行距/边距全局默认值配置（DataStore 持久化）。

### 7. 云同步后端与授权（P4/P5）

- **后端抽象层**：`core/cloud/` 下 `CloudBackend` 接口 + `CloudService` 编排层，统一 WebDAV 与百度两后端的不变量（先读列表、同名覆盖保留封面进度、uncertain 不报成功）。
- **WebDAV 后端**：`webdav/` 下路径安全校验（DavPath）、PROPFIND 解析（DavXml）、`WebDavBackend`（OkHttp、Basic 认证、条件写入 If-None-Match/If-Match、流式上传下载）。
- **百度网盘后端**：`baidu/` 下错误码映射（BaiduErrors）、大数安全解析（uk/fs_id 字符串承载防 2^53 精度丢失，BaiduJson）、表单编码（BaiduForm）、接口封装（BaiduHttp）、`BaiduBackend`（枚举分页/预创建-动态域名-4MiB 分片-提交上传/秒传/动态链接 7 小时缓存下载/删除幂等）。
- **百度 OAuth 授权**：`BaiduAuth`（授权 URL 构造 + 授权码换 token + uinfo 账户信息），OOB 授权码模式。
- **凭据安全存储**：`reader/` 下 `CredentialCrypto`（Android Keystore AES/GCM 加密，密钥不出设备）+ `CloudCredentialStore`（加密落盘 files/cloud_credentials，不落明文）。
- **后端配置 UI**：`app/CloudConfig.kt`，WebDAV 表单 + 百度 OAuth 两阶段授权（收集 AppKey/SecretKey/AppDir → 外部浏览器授权 → 回填授权码换 token）。

### 8. 本地朗读 TTS（P2）

- **句计划器**：`core/speech/SentencePlanner`（中英文句末标点分句、超长强制切段、逐字符锚点映射）+ `SpeechStateMachine`（Idle/Playing/Paused/Stopped 状态机，前后句、已确认进度）。
- **章节文本抽象**：`ChapterTextSource` + `SpeechSegment`（朗读纯文本 + 原文锚点 + 逐字符映射）。
- **TTS 引擎封装**：`speech/TtsEngine`（初始化/销毁、音色离线筛选、语速、朗读回调）+ `TtsVoice`（音色模型）。
- **前台朗读服务**：`speech/SpeechService`（MediaSession 控制、音频焦点、耳机断开暂停、前台通知），`SpeechCommands`（控制意图）、`SpeechPlanStore`（计划承载入口）。
- **进度桥接**：`SpeechProgressTracker`（TTS 偏移映射回原文锚点，供 UI 高亮与云端同步锚点）。

## 三、技术要点与踩坑沉淀（备忘）

- `view.open()` 无返回值，书籍对象在 `view.book`。
- `addJavascriptInterface` 必须在 `loadUrl` 前注入一次，`onPageFinished` 重复注入会覆盖成空对象。
- foliate-paginator 的 `scrolled` 模式默认不跨章节，需自行在 `#onTouchEnd` 检测边界切章节；其 `relocate` 的 `fraction` 在纵向滚动下有 bug，不可依赖。
- Compose `clickable` 会被 WebView 吞事件，需 `OnTouchListener + 手势判定`。
- `library.json` 协议强制 `title == bookId`，真实书名须存独立本地映射，避免破坏与 KOReader/BaiduPanSync 的兼容性。

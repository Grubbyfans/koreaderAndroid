## 二、导航架构（P0-1 修订）

### 2.1 三层职责划分

| 层 | 角色 | 是否可写 |
| --- | --- | --- |
| `CommittedPage`（页面 key） | **唯一已提交导航状态**，业务切书源/切栏目的依据 | 仅 `ShelfNavigator` 在“落页”时写 |
| `PagerState` | 视觉与手势状态 | 由手势/程序滚动驱动，不直接触发业务 |
| `currentTab` / `selectedProviderId` | 由 committed key **派生**，供顶栏、返回键、加载使用 | 只由 committed key 更新（对外只读） |

```kotlin
/** 稳定页面标识：跨进程重建、书源增删都以它为准，不用 index。 */
sealed interface ShelfPage {
    val key: String
    val tab: Tab

    data object LocalShelf : ShelfPage { override val key = "shelf.local"; override val tab = Tab.书架 }
    data class Cloud(val providerId: String) : ShelfPage {
        override val key get() = "cloud.$providerId"
        override val tab = Tab.云端
    }
    /** 全部书源被禁用时的云端占位页，保证一级“云端”仍可达且有空态。 */
    data object CloudEmpty : ShelfPage { override val key = "cloud.empty"; override val tab = Tab.云端 }
    data object Settings : ShelfPage { override val key = "settings"; override val tab = Tab.设置 }

    companion object {
        fun build(providers: List<BookProvider>): List<ShelfPage> = buildList {
            add(LocalShelf)
            if (providers.isEmpty()) add(CloudEmpty) else providers.forEach { add(Cloud(it.id)) }
            add(Settings)
        }
    }
}
```

### 2.2 统一导航入口

所有入口只调用一个控制器，不允许任何位置直接改 `currentTab` / `selectedProviderId`：

```kotlin
class ShelfNavigator(
    private val pages: List<ShelfPage>,
    private val pagerState: PagerState,
    private val scope: CoroutineScope,
) {
    var committed: ShelfPage by mutableStateOf(pages.first())
        private set
    var isNavigating by mutableStateOf(false)
        private set
    private val mutex = MutatorMutex()      // androidx.compose.foundation，已有依赖
    private var navJob: Job? = null
    private var pendingTargetKey: String? = null

    /** 点击/返回/外部跳转统一入口。 */
    fun navigateTo(key: String, animate: Boolean) {
        val target = pages.indexOfFirst { it.key == key }
        if (target < 0) return
        navJob?.cancel()
        navJob = scope.launch {
            mutex.mutate {
                isNavigating = true
                pendingTargetKey = key
                try {
                    val distance = abs(target - pagerState.currentPage)
                    // 相邻页用原生动画；跨多页直接定位，避免逐页展示中间栏目。
                    if (animate && distance == 1) pagerState.animateScrollToPage(target)
                    else pagerState.scrollToPage(target)
                } finally {
                    isNavigating = false
                }
            }
        }
    }

    /**
     * 落页（手势结束/动画结束）才提交业务状态。
     * 动画过程中的中间落页只有在命中目标页时才提交，避免提前切换业务书源。
     */
    fun onSettled(pageKey: String) {
        val target = pendingTargetKey
        if (isNavigating && target != null && pageKey != target) return
        committed = pages.firstOrNull { it.key == pageKey } ?: return
        if (pageKey == target) pendingTargetKey = null
    }
}
```

### 2.3 各导航入口的状态机

| 入口 | 行为 | 业务切换时机 |
| --- | --- | --- |
| 点击底部一级 | `navigateTo(目标页)`；云端目标页 = 上次有效书源 | 落页后 |
| 点击二级书源 Tab | `navigateTo(cloud.<id>)` | 落页后 |
| 手势滑动 | Pager 自身滚动 | `settledPage` 变化后提交 |
| 系统返回（云端） | `navigateTo("shelf.local")` | 落页后 |
| 系统返回（设置） | `navigateTo("shelf.local")`（评审决策 3） | 落页后 |
| 动态书源变化 | 按 `committed.key` 重定位；不存在则回退首个可用书源/`CloudEmpty` | 立即提交（无动画） |
| 快速连续点击 | `navJob.cancel()` 后最后一次生效，`MutatorMutex` 串行 | 仅最终落页 |
| 动画被手势打断 | 动画协程取消，`isNavigating=false`，不提交中间页 | 手势落页后 |
| 动画未完成 | 顶栏/菜单动作禁用（`isNavigating`），页面内操作只作用于自身 `providerId` | 落页后 |

### 2.4 为什么不会出现“提前切业务书源”

- `selectedProviderId` 仅由 `onSettled` 派生，不在点击瞬间写入。
- `navigateTo` 只动 Pager，不动 VM。
- 页面内容（列表/搜索/详情）由页面自己的 `providerId` 驱动，不读全局 selected，因此动画期间相邻页也可安全组合。
- 顶栏依赖 `committed`，动画期间仍显示旧栏目，避免标题与内容错位。

### 2.5 交互决策落地

| 决策 | 实现 |
| --- | --- |
| 设置首页参与滑动，全屏子页不参与 | `Settings` 在 pages 中；`fullscreenSubPage` 时 `userScrollEnabled=false` |
| 点击可跨多页，手势最多一页 | 距离 1 用原生动画；距离 > 1 用 `scrollToPage` 直接定位；`PagerSnapDistance.atMost(1)` |
| 设置返回回书库 | 设置页 `BackHandler` 改为 `navigateTo("shelf.local")`（原为退出） |
| 原生 Pager 动画、不逐页展示中间页 | 见上 |
| 开关默认开启、即时生效 | `ReaderPreferences.tabSwipeEnabled = true`，Compose 直接读 Flow，无需重启 |
| 点击云端恢复上次有效书源 | 目标页 = `lastCloudProvider`（校验仍在 enabled 列表）否则第一个书源 |
| 保留系统边缘返回 | 不添加 `systemGestureExclusion`，真机专项验证 |

## 三、网络请求与业务副作用（P0-2 修订）

### 3.1 职责审计

| 方法 | 实际职责 | 现状问题 | 修订 |
| --- | --- | --- | --- |
| `loadRemote(force=false)`（MainActivity） | 仅转调 `onlineVm.loadSelected(force)` | 无 | 改为 `loadProvider(committedProviderId, force=false)` |
| `loadSelected(force)` | 已加载且非强制直接返回缓存；云书源走 `provider.listBooks`；缓存命中时后台 `discoverExternalBooks` | 依赖全局 `selectedProviderId` | 增加 `loadProvider(id, force)`；`loadSelected` 变成 committed 便捷封装 |
| `selectProvider(id)` | 立即改 selected + 持久化 + **检索型直接 `loadQuota()`（网络）** + 云书源 `loadSelected` | 每次滑到 Z-Library 都会发额度请求；与菜单打开时的 `loadQuota()` 重复 | **删除 selectProvider 内的 `loadQuota()`**；额度只在“点击菜单额度行”或“打开更多菜单”时查询 |
| `LaunchedEffect(currentTab)` | 进入云端调用一次 `loadRemote` | Pager 下会在任意云端页/动画中触发 | 改为监听 **committed 页**：仅当 committed 为 `Cloud(id)` 且未加载时调用 |
| `refreshSelected()` | 主动刷新（用户手势/菜单） | 依赖全局 selected | 保留，但只由顶栏按钮在 `!isNavigating` 时调用 |
| Pager 预组合 | — | 若页面内放请求会误触发 | 页面组合**零请求**：所有请求放 VM + settled 事件 |

### 3.2 请求去重与验证

- 现有保护：`states[id].loaded/loading` 短路（`OnlineLibraryViewModel.kt:159-169`）；检索请求用 `jobs[id]` 取消旧任务 + `requestSeq` 丢弃旧响应。
- 新增保护：`loadProvider(id)` 内部对同 id 并发调用复用同一个 `Deferred`（`inFlight: MutableMap<String, Deferred<ProviderUiState>>`），彻底避免 Pager 抖动导致的双请求。
- 验证标准：
  - 同一书源往返滑动 10 次，`listBooks` 调用次数 = 1（首次）。
  - 从书库滑到 Z-Library 再滑回，额度接口调用次数 = 0（未打开菜单）。
  - 相邻页预组合期间，网络请求数 = 0。
  - 证据：测试版复用 `CloudSync` 诊断计数 + `adb logcat` 计数，记录在阶段 E 报告。

## 四、书源内容解耦（P0-3 修订）

### 4.1 现状问题

`OnlineLibraryScreen` 直接用 `vm.selectedState` 渲染内容，所有回调（搜索、筛选、分页、详情、刷新）内部也读全局 `selectedProviderId`。一旦相邻页同时组合，两页会显示同一书源内容，或在动画期间把操作写到错误书源。

### 4.2 目标结构

```kotlin
// 云端区域拆成「二级 Tab 行」+「按 providerId 绑定的页面内容」
@Composable
fun CloudTabsRow(providers: List<BookProvider>, committedProviderId: String?, onSelect: (String) -> Unit)

@Composable
fun ProviderPageContent(
    vm: OnlineLibraryViewModel,
    providerId: String,          // 页面唯一数据源标识
)
```

规则：
1. 页面状态一律 `vm.stateOf(providerId)`，不读 `selectedState`。
2. 所有回调传 `providerId`：`vm.searchIn(id)`、`vm.loadMoreIn(id)`、`vm.applyFiltersTo(id, …)`、`vm.openDetailIn(id, book)`、`vm.refreshProvider(id)`、`vm.loadQuotaFor(id)`。
3. `selectedProviderId` 仅保留给顶栏「更多」菜单与返回逻辑，且只由 committed 页更新。
4. `MainActivity` 中 `remoteBooks/remoteLoading/...` 镜像改为 committed 书源镜像（供设置页同步卡片、删除确认弹窗使用），页面内不再使用镜像。
5. 云书源适配器 `legacyIndex` 是实例级可变缓存，百度/WebDAV 分别为独立实例，Pager 相邻页不会串用。

### 4.3 涉及的 VM 改造清单

| 现有方法 | 改为 |
| --- | --- |
| `search()` | `searchIn(id)`（`search()` 保留为 committed 封装） |
| `loadMore()` | `loadMoreIn(id)` |
| `applyFilters(...)` | `applyFiltersTo(id, ...)` |
| `refreshSelected()` / `refreshCurrent()` | `refreshProvider(id)` |
| `openDetail(book)` / `closeDetail()` | `openDetailIn(id, book)` / `closeDetailIn(id)` |
| `loadQuota()` | `loadQuotaFor(id)`；`loadQuota()` = committed 封装 |
| `openPopular()` | `openPopularFor(id)` |
| `setKeyword(value)` / `toggleGridMode()` | `setKeywordIn(id, value)` / `toggleGridModeIn(id)` |

### 4.4 串页/重复验证

- 相邻页同时组合（滑动到一半停住）：两页列表分别对应各自 provider，标题/条目不同。
- 在 Z-Library 页搜索后滑到百度页再滑回：关键词、结果、滚动位置均属于 Z-Library。
- 快速滑动过程中点击列表项：详情归属被点击页的 provider。
- 单测：同一 VM 内 `stateOf("baidu")` 与 `stateOf("webdav")` 写入互不影响（JVM 可测部分抽纯逻辑）。

## 五、滑动闸门（P1-1 修订）

不使用单一 Boolean，改为**禁止原因 token 集合**：

```kotlin
class SwipeBlockRegistry {
    private val reasons = mutableStateSetOf<String>()
    val blocked: Boolean get() = reasons.isNotEmpty()

    /** 页面用 DisposableEffect 注册，onDispose 精确回收，避免残留。 */
    fun hold(reason: String) { reasons += reason }
    fun release(reason: String) { reasons -= reason }
}
```

组合条件（动画期间仍允许手势打断，由 Compose 自动取消动画；是否提交以 settledPage 为准）：

```kotlin
val tabSwipeEnabled by ReaderSettings.flow(context)
    .map { it.tabSwipeEnabled }
    .collectAsState(initial = true)

val userScrollEnabled = tabSwipeEnabled && !swipeBlockRegistry.blocked
```

> 顶栏的「更多」等动作在 `isNavigating` 期间禁用，避免用旧/新书源状态发起业务操作。

| token | 注册方 | 触发/回收 |
| --- | --- | --- |
| `sel:local` | 本地书库 | `selecting != null` / 退出管理态 |
| `detail:<providerId>` | 云端详情页 | `state.detail != null` / 关闭详情 |
| `filter:<providerId>` | Z-Library 筛选弹窗 | 弹窗打开 / 关闭 |
| `focus:<providerId>` | 搜索框 | `onFocusChanged(true)` / 失焦或页面销毁 |
| `subpage:settings` | 设置全屏子页 | `fullscreenSubPage` / 返回首页 |
| `overlay:downloads` | 下载管理 | 覆盖页可见 / 关闭 |

保证：
- 多条件并存时取并集，全部释放才恢复滑动。
- `DisposableEffect(token)` 的 `onDispose` 保证页面销毁必回收；另有 `ShelfNavigator` 提交新页时统一 `releasePageTokens(oldKey)` 兜底。
- 搜索框失焦只 `clearFocus()`，**不调用 `clearSearch()`**，已有结果与关键词保留。

## 六、动态书源边界（P1-2 修订）

| 场景 | 处理 |
| --- | --- |
| 全部书源被禁用 | pages = `[书库, CloudEmpty, 设置]`；云端页显示空态：「暂无启用的书源，去设置开启」+ 跳转设置按钮 |
| 启用/禁用书源 | `pages` 重建；以 `committed.key` 查找新 index；找不到则回退首个可用 `Cloud(id)`，再退 `CloudEmpty`；用 `scrollToPage` 无动画重定位 |
| 书源排序变化 | 同上；禁止在动画中重建 pages（`isNavigating` 时排队到落页后） |
| `lastCloudProvider` 无效 | 初始化回退链：`lastCloudProvider`（且 registry 中存在且 enabled）→ 第一个 enabled 书源 → `CloudEmpty` |
| 进程重建 | `rememberSaveable` 保存 `committedKey`；恢复到对应页；书源被删则按回退链 |
| 正在滑动的书源被禁用 | 立即取消手势动画（`pagerState.scrollToPage(新 index)`），提交新页，闸门重算 |

### 7.1 百度网盘 / WebDAV 目录与排序（源码审计结论）

| 检查项 | 结论 | 证据 |
| --- | --- | --- |
| 当前目录路径 | **当前不存在**。云端列表为扁平列表，UI 无目录层级 | `CloudSync.RemoteBook` 仅 bookId/fileName/size/cover；`CloudBookshelfContent` 无路径控件 |
| 目录返回栈 | **当前不存在** | 同上 |
| 排序方式 | **当前不存在**（云端列表顺序由后端/缓存决定；本地书架仅按 `lastReadAt` 排序） | `CloudBookProviderBase.listBooks` 未暴露排序参数 |
| 分页游标 | 未使用 | `listBooks(directory, cursor, force)` 中 `directory`/`cursor` 均被忽略（`CloudBookProviderBase.kt:62-77`） |

处理方式：
- 本期**不新增**目录/排序功能，只保证现有扁平列表在 Pager 下状态正确。
- 现有可保留状态：列表数据（`states[providerId].items`）、加载/错误/缓存标记、滚动位置（`cloud.<providerId>`）。
- 若后续引入目录/排序，约束为：必须存入 `ProviderUiState`（按 providerId 隔离），不得放页面 `remember`；本次方案预留字段位置但不实现。

### 7.2 Z-Library 搜索状态

- 关键词、已提交关键词、结果、分页游标、来源（关键词/热门）、筛选、详情、额度均在 `ProviderUiState`，按 providerId 隔离。
- 切入切出、跨书源滑动、进程重建（仅关键词不持久化，按现有产品定义）均不串页。
- 焦点解除只清焦点；系统返回清空检索是既有独立交互，保持不变。

### 7.3 设置页滚动与收起

- 新增 `LibraryUiPrefs.settingsScroll`（index+offset）或 `rememberSaveable(ScrollState.Saver)`；优先 prefs，避免依赖 Pager 的 Saveable 行为。

## 十一、风险与缓解（更新）

| 风险 | 缓解 |
| --- | --- |
| 动画/手势与 committed 不一致 | 只认 settledPage；`isNavigating` 期间不提交 |
| 快速连点导致多次请求 | 导航 Mutex + `inFlight` 复用 |
| 相邻页串页 | 页面强制 providerId 参数化，禁止 selectedState |
| 闸门残留 | token + DisposableEffect + 切页兜底释放 |
| 书源列表变化导致错页 | key 重定位 + 回退链 + 动画中排队 |
| 预组合触发请求 | 组合零请求，请求只由 settled 事件发起 |
| 设置滚动/搜索结果丢失 | prefs/VM 提升；失焦不清检索 |
| 系统返回手势冲突 | 真机专项验证，必要时限制边缘手势区由系统优先 |
| 低端机掉帧 | 页数少、`beyondViewportPageCount=0`、必要时封面缓存 |

## 十二、回退方案

1. **用户级**：设置关闭「栏目滑动切换」，Pager 保留但禁滑，行为等价当前版本。
2. **代码级**：阶段 A–D 独立提交，可单独 revert 阶段 C（手势）恢复“只点击不滑动”；不改数据层。
3. **降级**：若扁平 Pager 出现不可解问题，退回“仅一级 3 页 Pager、云端二级不滑”，保留页面模型与开关。

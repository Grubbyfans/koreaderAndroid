# 静读 Android 在线书库统一化与多书源扩展技术方案

版本：1.0（阶段 A 最终确认修订） | 用途：开发及验收依据

> **阶段 A 最终确认结论（2026-11-24）优先于本文原有假设**；冲突处以《阶段 A 报告》§7 的最终决策为准。核心变更：书籍唯一性仅按**文件名（含扩展名）**判断，取消哈希/元数据三级去重、自动唯一文件名与三选一弹窗，改为**同名覆盖确认弹窗**；保持现有两项底部导航，书源切换置于「云端」作用域内。

## 1. 目标与范围

统一百度网盘、WebDAV 和 Z-Library 在线书源入口，保留现有云端书库及 KOReader 同步能力。新增检索、详情、EPUB 下载、自动导入、手动上传云端、统一下载管理及配置导入。保持本地优先，不引入自建后台。

参考仓库：https://github.com/ZlibraryKO/zlibrary.koplugin 。实施前固定 commit SHA，核实接口、文件结构和许可证；非公开 API 可用性不作保证，仅测试和获取具有合法授权的资源。

本文中的 Kotlin 类型、目录、CloudBackend、library.json 和书籍 ID 规则均为设计建议或此前方案假设，必须先核对实际源码，不得凭空创建重复模块。

## 5. 接口及模型

```kotlin
enum class ProviderCapability {
    BROWSE, SEARCH, FILTER, BOOK_DETAIL, DOWNLOAD, UPLOAD,
    DELETE, PROGRESS_SYNC, DOWNLOAD_QUOTA, CUSTOM_SERVER, IMPORT_CONFIG
}
interface BookProvider {
    val id: String
    val displayName: String
    val capabilities: Set<ProviderCapability>
    suspend fun getConnectionState(): ConnectionState
    suspend fun getBookDetail(remoteId: String): OnlineBook
    suspend fun download(request: BookDownloadRequest, target: File,
        onProgress: (Long, Long?) -> Unit): DownloadResult
}
interface CloudBookProvider : BookProvider {
    suspend fun listBooks(directory: String, cursor: String?): BookPage
    suspend fun upload(localBook: File): UploadResult
}
interface CatalogBookProvider : BookProvider {
    suspend fun search(query: SearchQuery): BookPage
}
data class OnlineBook(
    val providerId: String, val remoteId: String, val title: String,
    val format: String, val authors: List<String> = emptyList(),
    val coverUrl: String? = null, val description: String? = null,
    val publisher: String? = null, val publishYear: Int? = null,
    val isbn: String? = null, val language: String? = null,
    val fileSize: Long? = null, val remotePath: String? = null,
)
data class SearchQuery(val keyword: String, val language: String? = null,
    val format: String? = "epub", val sort: String = "relevance",
    val cursor: String? = null, val pageSize: Int = 30)
data class BookPage(val items: List<OnlineBook>, val nextCursor: String?,
    val hasMore: Boolean, val totalCount: Int? = null)
```

上述未定义类型由实际工程补齐。UI 根据能力声明控制按钮；账号作用域、书源实例 ID 和 remoteId 共同标识远程资源。远程 ID 不得替代现有本地 bookId；本地书籍唯一性按文件名（含扩展名）判断，详见 §8。

Z-Library 接口默认参数以参考实现为准：搜索为 `POST /eapi/book/search`，分页 `limit=30`，排序映射为 `order` 数组，搜索免登录、下载需登录。

## 6. 书源配置与安全

采用内置适配器 + 外部 JSON 配置，不实现动态脚本引擎。参考仓库中的网络、认证、数据映射和异常处理思想，重新实现 Android 适配。先核实许可证兼容性，避免未经许可复制代码。

配置示例（占位地址，不是真实接口）：

```json
{
  "schemaVersion": 1,
  "providerId": "zlibrary",
  "configVersion": "1.0.0",
  "servers": {"mode": "auto", "baseUrls": ["https://example.com"]},
  "network": {"connectTimeoutMs": 15000, "readTimeoutMs": 30000},
  "endpoints": {"search": {"path": "/example/search", "method": "GET"}},
  "preferences": {"defaultLanguage": "zh", "defaultFormat": "epub", "pageSize": 20}
}
```

配置优先级：用户有效配置 > 内置配置 > 安全默认值。支持配置版本管理、格式校验、连接测试、配置回滚与恢复默认配置；导入无效配置时不得覆盖当前可用配置。认证凭证（账号密码、Token、Cookie）必须独立加密存储，不得随配置文件导入或导出，不得明文写入 JSON。导入前校验 schema、版本、字段、HTTPS 地址及可信主机；失败不覆盖，保留上一份配置并支持回滚。禁止任意代码执行、关闭 TLS 验证或向未知主机转发凭证；重定向亦需校验。账号凭证采用 Android Keystore 支持的加密存储，按书源及账号隔离。日志和导出配置不得包含密码、Token、Cookie。

## 7. 下载管理

```text
QUEUED → PREPARING → DOWNLOADING → VERIFYING → IMPORTING → COMPLETED
                         └── FAILED / CANCELLED
                                      IMPORT_FAILED → 重试导入
```

任务字段：taskId、providerId、accountScope、remoteId、bookTitle、fileName、status、downloadedBytes、totalBytes（可空）、localPath、errorCode、createdAt、updatedAt。

默认并发 2；流式写入应用专属目录的 taskId.part；进度每 500–1000ms 更新，未知总大小使用不定进度。取消网络请求并清理临时文件；仅对安全可重试的网络错误最多自动重试两次，额度、认证、限流错误不盲目重试。断点续传必须确认服务支持及资源版本一致。后台任务采用现有机制或按 Android 版本选择 WorkManager、前台服务等合规机制。

书籍唯一性按**文件名（含扩展名）**判断：可在下载前确定最终文件名时先检查，避免浪费下载额度；不能确定时在实际文件名确定后检查；正式导入前必须再次检查（防并发冲突）。同名时弹出「书籍已存在」确认弹窗（取消 / 确认覆盖），不自动生成唯一文件名。

下载完成检查 HTTP 状态、文件类型、大小及 EPUB ZIP、mimetype、container.xml、OPF；限制解压体积与路径，防止 ZIP bomb 和路径穿越。EPUB 有效性校验仅用于判断下载文件是否有效，**不用于书籍重复判断**。拒绝 HTML/JSON 错误页。校验成功后原子移动至待导入目录，再调用现有导入逻辑。导入失败保留文件，禁止重复消耗下载额度。下载过程中使用独立临时文件，不直接写入原有书籍路径；下载失败、校验失败、替换失败或用户取消时不得损坏原有书籍。同名覆盖须串行执行，并使用安全替换机制（必要时保留临时备份）；正在阅读的书籍待阅读器释放后再覆盖。不得静默覆盖已有文件。

重启恢复：等待任务恢复队列；下载中检查临时文件及续传条件；校验中重新校验；导入中检查是否已完成（保证幂等）；失败等待用户操作；取消清理残留。对于有额度限制的服务，不自动重新申请下载。

## 8. 唯一性判断、映射及同步

**唯一性判断以文件名（含扩展名）为准**：文件名相同即同一书籍，文件名不同即不同书籍（即使内容完全一致）。不使用 SHA-256/MD5 等文件哈希，不使用书名、作者、ISBN、出版社、文件大小等元数据，不使用在线书源远程 ID 判断重复。比较规则与现有本地书库及云端同步规则一致。

| 场景 | 处理方式 |
|---|---|
| 文件名不存在 | 正常下载并调用现有导入器 |
| 文件名已存在 | 弹出覆盖确认弹窗 |
| 用户确认覆盖 | 安全替换原有书籍文件 |
| 用户取消覆盖 | 取消本次下载或导入，保留原有书籍 |
| 文件名不同但内容相同 | 作为不同书籍正常导入 |
| 文件名相同但内容不同 | 由用户决定是否覆盖 |

覆盖确认弹窗：标题「书籍已存在」；提示「本地书库中已存在同名书籍「{fileName}」，是否覆盖？覆盖将替换原有书籍文件，并保留原有阅读进度和书签。如果新旧书籍版本不同，阅读位置可能存在偏差。」；按钮「取消」「确认覆盖」。不提供「保留两个版本」选项，不自动生成唯一文件名，不自动添加 `(1)`、`(2)` 等后缀。

覆盖后保留原有 bookId、本地书籍数据库记录、阅读进度、书签、阅读历史及云端同步关系；重新提取 EPUB 元数据，更新文件大小与修改时间，刷新封面，清理旧文件对应的章节解析及阅读缓存，刷新本地书库；不主动重置阅读进度，不自动修改云端书籍文件。内部章节结构不同导致阅读位置偏差时，不得主动删除原有阅读记录。

`online_book_mapping` 字段：providerId、accountScope、remoteId、localBookId、downloadedAt。**该表仅用于展示下载状态与关联关系，不作为书籍重复判断依据。** 下载状态与云端同步状态分别管理；删除本地书籍后应更新映射状态，不误判已下载。

下载完成 → 本地导入 → 用户选择上传百度网盘或 WebDAV → 复用原有云端索引更新 → KOReader 下载及进度同步。默认手动上传，两个云端目标分别记录成功或失败，不因其中一个失败回滚另一个。保持原有 bookId、目录、索引和进度协议；不创建第二套云端目录。本地文件覆盖不自动触发云端文件覆盖；原有云端同步冲突处理机制保持不变。自动上传留待后续版本。

以上规则统一适用于百度网盘、WebDAV、Z-Library 及后续新增书源。原「三级去重」「哈希判重」「元数据判重」「保留两个版本」「重名三选一弹窗」「自动生成唯一文件名」设计已删除。

## 9. 数据库与缓存

优先复用现有表，仅增量新增 `online_download_task`（下载任务、状态、失败重试及历史记录）与 `online_book_mapping`（在线书籍与本地书籍关联及下载状态展示）两张表。书源配置使用 JSON 文件管理，不新增配置表；搜索结果优先内存缓存；封面复用现有图片缓存；暂不新增独立的在线书籍元数据缓存表。迁移必须保留原有数据，禁止 destructive migration。账号密码、Token、Cookie 等敏感认证信息独立加密存储，不得明文写入 JSON 配置文件。

建议缓存：搜索结果内存 10 分钟；详情 24 小时；封面复用现有磁盘缓存；服务器检测短期缓存；额度下载后刷新；云存储保持原有策略。账号退出清理对应私有缓存。清理缓存不得删除本地书籍、下载历史或待导入文件。

文件建议目录：files/downloads/temporary、files/downloads/pending_import、files/providers/configs、cache/online_covers。不得迁移现有书籍目录。网络、校验和文件写入不得阻塞主线程。

## 10. 错误处理

| 错误 | 行为 |
|---|---|
| 网络不可用/超时 | 保留列表，允许重试 |
| 认证过期 | 提示重新登录 |
| 额度耗尽/限流 | 停止自动重试 |
| API 不兼容 | 提示检查配置，不影响其他书源 |
| 配置非法 | 保留原配置 |
| 文件损坏/格式不支持 | 拒绝导入 |
| 空间不足 | 提示清理空间 |
| 导入失败 | 保留文件，独立重试 |

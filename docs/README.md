## 维护约定

1. 新增文档按功能放入对应子目录，并同步更新本索引；不要再把 `.md` 直接平铺在 `docs/` 根目录。
2. 文档正文引用其他文档时，路径**一律从项目根算起**（例如 `docs/04-在线书库统一化/阶段B-实施报告.md`），不要用相对路径，这样无论文档在哪个子目录都不会指错。
3. 本索引内的链接使用相对路径，便于直接点击跳转。
4. 保留测试版包名 `com.yuezhou.reader.tts.test` 与应用名「静读测试版」；构建命令见 `01-工程与构建/BUILD.md`。
